# 05.Sim/matrix_inv

One testbench per algorithm, each sweeping `N = 2, 3, 4` against vectors
generated by `03.Reference/tools/gen_matrix_inv_vectors.py` (arrives in
Sprint 1).

| Module               | Testbench               | Status          |
| -------------------- | ----------------------- | --------------- |
| `matrix_inv_gj.v`  | `tb_matrix_inv_gj.v`  | 36/36 passing   |
| `matrix_inv_cof.v` | `tb_matrix_inv_cof.v` | not implemented |
| `matrix_inv_lu.v`  | `tb_matrix_inv_lu.v`  | not implemented |
| `matrix_inv_qr.v`  | `tb_matrix_inv_qr.v`  | not implemented |

Also: `common/tb_divider_q88.v`, a standalone regression for the shared
divider (8 fixed vectors: fractions, signs, self-division, saturation).

## How to run

Needs [Icarus Verilog](http://iverilog.icarus.com/) (`iverilog`/`vvp`) on
`PATH`. From this directory (`05.Sim/matrix_inv`):

```
make all          # tb_divider + tb_gj -- everything currently validated
make tb_gj        # just the Gauss-Jordan testbench
make tb_divider   # standalone divider regression (8 fixed vectors)
make clean        # remove compiled .vvp files
make help         # list all targets
```

`make tb_cof` also exists (compiles and runs `tb_matrix_inv_cof.v`) but
is deliberately left out of `make all`: `matrix_inv_cof.v` is still being
checked — see the status table above.

Equivalent raw commands, if you'd rather not use `make` (or need to see
exactly what's being compiled):

```
cleaiverilog -g2005 -o tb_matrix_inv_gj.vvp \
    ../../04.RTL/matrix_inv/common/divider_q88.v \
    ../../04.RTL/matrix_inv/matrix_inv_gj.v \
    tb_matrix_inv_gj.v
vvp tb_matrix_inv_gj.vvp
```

The `.hex` vectors under `vectors/gj/` are already committed; to
regenerate them, see `03.Reference/README.md`.

## Vector layout (per test case)

```
vectors/<algo>/n<N>/
    cases.txt              # one case folder name per line, for humans/tooling
    case_<idx>_<category>/
        A.hex               # N*N lines, row-major, 4 hex digits (Q8.8 two's complement)
        b.hex               # N lines
        x_expected.hex      # N lines
        ainv_expected.hex   # N*N lines, row-major
        meta.json           # {"category": ..., "singular_expected": bool} (human/Python)
        singular.txt        # "0" or "1" (same value as meta.json, Verilog-friendly)
```

`category` covers: well-conditioned, near-singular (pivot just above
`EPSILON_Q88`), and singular (pivot below `EPSILON_Q88` — `done` must
still pulse with `singular=1`, per the interface contract).
